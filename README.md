# reproducibility-traffic-light
The Reproducibility Traffic Light is an objective screening tool based on FAIR principles, consisting of ten questions distributed across four dimensions: data; code and environment; method and protocol; and access and credit. The tool allows for the assessment of an article's reproducibility level in just a few minutes.
