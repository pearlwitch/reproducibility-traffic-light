# reproducibility-traffic-light
O Semáforo da Reprodutibilidade é uma ferramenta de triagem objetiva baseada nos princípios FAIR, composta por dez perguntas distribuídas em quatro dimensões: dados; código e ambiente; método e protocolo; e acesso e crédito. A ferramenta permite diagnosticar, em poucos minutos, o nível de reprodutibilidade de um artigo.
